# 📖 About The Project

The **MERN Job Portal** is a full-stack recruitment platform designed to simplify the hiring process for both employers and job seekers.

Employers can create and manage job listings, while job seekers can browse, search, filter, and apply for opportunities through a secure and user-friendly interface.

The application follows a **role-based authentication system** using JWT and provides dedicated dashboards for both users and employers.

Whether you're hiring talent or searching for your next opportunity, this platform offers a modern recruitment experience with an intuitive interface and responsive design.

# 🗄 Database Collections

The application uses MongoDB with multiple collections to manage users, employers, jobs, and applications.

| Collection | Purpose |
|------------|---------|
| Users | Stores job seeker information |
| Employers | Stores employer/company details |
| Jobs | Stores job postings |
| Applications | Stores applied job records |
